41 Vérifications

Chaque dimension Oracle
couverte en détail

Des checks réels, écrits par un DBA de production — pas des métriques génériques copiées d'une documentation.

Instance & Disponibilité (5)
  • Statut instance (OPEN/ACTIVE)
  • Mode ARCHIVELOG / FLASHBACK
  • Statut PDBs (CDB/Multitenant)
  • Redo logs & switching rate
  • Paramètres non-défaut
Stockage (7)
  • Utilisation tablespaces (+ tendance AWR)
  • TEMP & UNDO + top consommateurs
  • AUTOEXTEND & MAXSIZE
  • ASM disk groups
  • Top 15 segments par taille
  • Fast Recovery Area
  • Segment Advisor — fragmentation
Performance & SQL (9)
  • Sessions actives + AAS (ASH)
  • Sessions bloquantes (arbre récursif)
  • Top 15 SQL par elapsed time
  • Top 15 SQL par I/O physique
  • Wait events distribution
  • Hit ratios (Buffer/Library/Dict)
  • Latch & mutex contention
  • SQL Plan Management (SPM)
  • Requêtes longues actives
Mémoire (3)
  • SGA dynamique + resize errors
  • PGA advisor + top consommateurs
  • In-Memory Column Store (IMC)
Backup & Recovery (3)
  • Jobs RMAN + âge dernier backup
  • Archive logs + détection de gap
  • Datafiles nécessitant recovery
Data Guard & RAC (2)
  • Lag transport/apply + MRP/LNS
  • Instances RAC + interconnect
Sécurité (4)
  • Comptes lockés/expirés/expirant
  • Inventaire rôle DBA & privilèges
  • Logins échoués 24h (brute force)
  • Mots de passe Oracle par défaut
Objets & Maintenance (4)
  • Objets invalides (packages, views...)
  • Statistiques obsolètes
  • Jobs DBMS_Scheduler en erreur
  • Auto Indexing Oracle 19c
OS & Infrastructure (4)
  • CPU / RAM / Swap
  • Erreurs ORA- dans alert log (24h)
  • Configuration AWR/rétention
  • Listener & DB Links

Comment ça marche

Opérationnel en 3 étapes

Installation en 2 minutes. Aucun Oracle Client. Aucune dépendance externe.

1
Installer
Python 3.9+ requis. Un script d'installation automatique configure tout.
pip install oracledb rich pyyaml jinja2
2
Configurer
Renseigner host, port, service_name et credentials dans config/databases.yaml. GUI Tkinter disponible.
python hc_config.py
3
Analyser
Lancer l'analyse. Le rapport HTML s'ouvre automatiquement. Planifier via cron ou Task Scheduler pour une surveillance continue.
python hc_collector.py --html --alert
